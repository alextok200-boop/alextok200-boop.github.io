Web UI 设计模式演示

基于 7 种现代前端设计模式，应用于霓虹暗黑风格网站

1. 留白系统 (Whitespace)

留白是呼吸空间，不是白色背景。通过间距控制节奏感。

紧凑布局

元素间距小，信息密度高，适合数据表格。

标准布局

平衡的间距，适合大多数内容展示场景。

宽松布局

大间距营造高端感，适合展示重要内容。

2. 栅格系统 (Grid)

12列标准栅格，响应式断点适配各种屏幕。

列 5-8

3. 卡片微交互 (Card + Micro)

悬停提升、边框发光、标签变色等微交互动效。

霓虹绿

发光效果

悬停时产生霓虹光晕，增强视觉吸引力。

折射效果

高光扫过

悬停时一道高光从左上滑到右下。

基础卡片

标准卡片

简洁的卡片样式，适合大多数场景。

4. 瀑布流 (Masonry)

CSS Column 方案实现不等高卡片瀑布流布局。

短内容

这是简短的内容展示。

长内容

这是较长的内容，会占据更多垂直空间，用于展示瀑布流的效果。内容可以有不同的长度，形成错落有致的布局。

中等内容

这是中等长度的内容展示。

5. 液态玻璃 (Liquid Glass)

毛玻璃效果，backdrop-filter 模糊+饱和，营造通透感。

玻璃卡片

半透明背景 + 模糊效果，背景内容隐约可见。

6. 骨架屏 (Skeleton)

加载占位符，渐变动画模拟内容加载状态。

7. 空状态 (Empty State)

数据为空时的友好提示，引导用户操作。
