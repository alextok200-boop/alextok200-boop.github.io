作品集

把 70+ 项自研与改良 AI 技能，串成 7 条能自己转起来的端到端业务闭环。

7 条端到端闭环
71 项技能串联成环
95 项技能资产 · 自研 38 + 半自研 57
01

投流投放闭环

8项技能

对标分析 → 计划生成 → 台球专项 → 合规审核 → 执行方案 → 汇率核算 → 数据复盘 → 回灌下一轮

从竞品广告对标到复盘回灌的自动投流流水线：台球专版生成器 + 7 维审核器 + 执行方案，覆盖 12 个投放平台，汇率核算进投放成本。

落点：投流计划 + 复盘战报

02

跨境销售数据看板闭环

14项技能

平台采集 → SP-API → ERP 接入 → 财务核算 → 店铺看板 → 数据战报 → 整页截图 → 钉钉推送 → 数据回收

六大平台销售数据每日自动汇入，双 ERP 财务核算，ECharts 看板配整页截图，钉钉摘要同时推管理端与员工端。

落点：钉钉每日数据看板 + 财务核算

03

内容生图视频闭环

17项技能

题材情报 → 批量生图 → 视觉审计 → 短视频 → 带货脚本 → 品牌包装 → 社媒卡图 → 数据回收

从台球趋势情报到成片发布的视觉生产线：批量生图、主图质检评分、短视频与带货脚本，产出统一走品牌规范。

落点：短视频 + 主图 + 社媒素材

04

钉钉协作办公闭环

10项技能

表结构重整 → 计算字段 → 看板聚合 → Webhook 注册 → OA 审批 → 文档报表 → 结果回灌

钉钉 AI 表格的结构迁移、计算字段抓取、OA 审批与推送注册串成一条线，审批结果自动回流表格。

落点：钉钉协作自动化

05

品牌情报与逆向合规闭环

9项技能

趋势情报 → 比价监控 → 自动巡检 → 逆向总控 → 报关填写 → 达人线索 → 回灌投流

台球品类的情报—逆向—合规链路：趋势与比价监控、竞品自动化巡检、报关单自动填写，产出直接喂给投流与招商。

落点：情报报告 + 报关单 + 招商线索

06

商品运营上架闭环

5项技能

标题生成 → 主图制作 → 视觉质检 → 广告对标 → 落地文案 → 销售回流

从速卖通标题生成校验起步，串起商品图制作、主图质检、竞品广告对标与落地页文案，销售数据回流优化标题。

落点：上架商品页

07

技能工程自研闭环

8项技能

脚手架 → 安全审计 → 设计转码 → 前端落地 → Git 发布 → 一键安装 → 市场检索 → 回归脚手架

技能本身的流水线：骨架生成、第三方准入审计、Figma 转码与前端落地、Git 发布，再到零基础同事可用的一键安装包。

落点：新技能包
