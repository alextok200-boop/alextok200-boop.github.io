发布工作流

  1. 在本地仓库目录（C:\Users\alext\Web\personal-site）新增或修改内容文件
  2. 同步 bump 全站版本号：所有 HTML 的 ?v= 参数 + sw.js 内的 konllen-site-vX.Y.Z
  3. 本地跑版本门禁自检：python tools/check_version.py
  4. 提交并推送：git add -A && git commit -m "..."，再推送至远端
  5. 等待约 50 秒 CDN 生效后，访问线上地址复核关键节点
